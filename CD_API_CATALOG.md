# Client Dynamics API Catalog
# Verified Structure: Contacts, Policies, Quotes

## 1. Contacts
- List: GET /Contacts/list (Parameters: search_criteria, search_value, limit, sort)
- Add: POST /Contacts/add
- Update: POST /Contacts/update

## 2. Policies
- List: GET /Policies/list (Parameters: search_criteria, search_value, limit, sort)
- Add: POST /Policies/add
- Update: POST /Policies/update

## 3. Quotes
- List: GET /Quotes/list (Parameters: search_criteria, search_value, limit, sort)
- Submit: POST /Quotes/submitQuoteRequest
