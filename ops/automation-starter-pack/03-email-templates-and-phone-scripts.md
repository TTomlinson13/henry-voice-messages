# Starter Templates (Email) + Phone Script Flows

Keep templates short, warm, and action-forward.

## A) Email Templates (10)

### 1) COI Request Acknowledgement
Subject: Re: COI Request Received
Body:
Hi {{first_name}},

Got it — we received your COI request and are working on it now.
If you have a deadline, reply with the exact date/time and recipient details so we can prioritize correctly.

Best,
{{agent_signature}}

### 2) Missing COI Details
Subject: Re: COI Request — Quick Details Needed
Body:
Hi {{first_name}},

I can finish this quickly once I have:
- Certificate holder legal name
- Holder address/email
- Any additional insured wording
- Deadline

Send those and we’ll finalize right away.

Best,
{{agent_signature}}

### 3) Dec Page / Policy Copy Request
Subject: Re: Policy Document Request
Body:
Hi {{first_name}},

Absolutely — we can send that over.
Please confirm policy number (or insured property/address) so we provide the correct document.

Best,
{{agent_signature}}

### 4) Billing Question Received
Subject: Re: Billing Question
Body:
Hi {{first_name}},

Thanks — we received your billing question and are reviewing the account details now.
If you have a cancellation/non-pay date listed, please share it so we can prioritize.

Best,
{{agent_signature}}

### 5) Cancellation Warning Escalation
Subject: Re: Urgent — Cancellation Notice
Body:
Hi {{first_name}},

Thanks for sending this. We marked it urgent and are reviewing reinstatement/payment options now.
Please confirm the cancellation effective date/time shown on your notice.

Best,
{{agent_signature}}

### 6) New Quote Intake Confirmation
Subject: Re: Quote Request Received
Body:
Hi {{first_name}},

Great — we have your quote request.
Next step: we’ll review and send any missing-info request shortly so we can move to pricing.

Best,
{{agent_signature}}

### 7) Quote Follow-Up
Subject: Re: Quote Follow-Up
Body:
Hi {{first_name}},

Just checking in on your quote for {{line_of_business}}.
If helpful, we can do a quick call to review options and finalize next steps.

Best,
{{agent_signature}}

### 8) Renewal Shopping Kickoff
Subject: Re: Renewal Review
Body:
Hi {{first_name}},

Perfect timing — we can start your renewal review now.
Please send your current dec page and any recent loss/activity updates so we can market accurately.

Best,
{{agent_signature}}

### 9) Claim Status Routing
Subject: Re: Claim Status Request
Body:
Hi {{first_name}},

Thanks — we received your claim status request and are checking current carrier/adjuster updates.
If you have the claim number handy, reply with it for fastest handling.

Best,
{{agent_signature}}

### 10) Internal Handoff to Human Specialist (Client-Facing)
Subject: Re: Your Request
Body:
Hi {{first_name}},

I’ve routed this to the right specialist on our team so you get a precise answer.
We’ll follow up shortly with next steps.

Best,
{{agent_signature}}

## B) Phone Script Flows (5)

### Flow 1: COI Request
1. Greeting + verify caller identity
2. Confirm holder details + deadline
3. Confirm additional insured wording
4. Commit turnaround window
5. Close with callback/email confirmation

### Flow 2: Billing/Cancellation Warning
1. Verify identity + policy/account
2. Capture cancellation effective date/time
3. Confirm whether payment already attempted
4. Escalate to billing specialist immediately
5. Provide expected callback window

### Flow 3: New Quote Intake
1. Verify contact/business details
2. Capture line of business + effective date
3. Gather key underwriting basics
4. Confirm missing docs list
5. Schedule follow-up milestone

### Flow 4: Claim Status
1. Verify identity
2. Capture claim number + date of loss
3. Identify adjuster/carrier contact in record
4. Set expectation on status callback timing
5. Send written recap if requested

### Flow 5: Complaint / Legal Mention
1. Calm acknowledgment
2. Verify identity + issue summary
3. Do NOT argue coverage on call
4. Escalate to manager/compliance lane immediately
5. Promise timed follow-up by designated owner
