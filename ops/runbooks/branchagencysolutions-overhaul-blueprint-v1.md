# BranchAgencySolutions.com Overhaul Blueprint (v1)

## Objective
Rebuild Branch Agency Solutions into a modern MGA authority site that drives producer/agency submissions, showcases private flood expertise, and routes opportunities into a unified operations pipeline.

## Strategic Role
- **Primary brand role:** MGA authority platform (flood-first, multi-line capability)
- **Audience:** retail agents, partner agencies, distribution channels, and select direct prospects
- **Business goal:** increase qualified submissions and partner onboarding

---

## 1) Core Positioning

### Primary Promise
Private flood and specialty solutions with faster response, cleaner underwriting intake, and dependable agency support.

### Message Pillars
1. MGA expertise (not generic retail quoting)
2. Private flood depth + additional lines
3. Fast turnaround and clear submission standards
4. Partner-first service model

---

## 2) Required v1 Sitemap
1. Home
2. Flood Programs
3. Other Lines / Markets
4. For Agents (Appetite + Submission Guidelines)
5. Become a Partner
6. About Branch Agency Solutions
7. Contact / Submission
8. Compliance, Licensing, Privacy, Disclosures

Optional v1.1:
- Carrier/market spotlight page
- Resource center (forms, underwriting tips)
- Case studies/testimonials

---

## 3) Homepage Conversion Structure

### Above the Fold
- Headline: MGA authority + private flood strength
- Subhead: fast submission-to-response promise
- Primary CTA: Submit a Risk
- Secondary CTA: Become a Partner

### Trust Strip
- Years in market
- States served
- Program types
- Service SLA commitment

### Program Blocks
- Private Flood
- Coastal/Challenging Risks
- Additional specialty/commercial options

### Operational Proof
- Intake standards
- Turnaround expectations
- Dedicated support flow

---

## 4) Submission Flow Design

### Step 1 (Fast Intake)
- Producer/agency name
- Insured name
- Risk type/line
- Property address/state
- Contact email/phone

### Step 2 (Structured Details)
- Coverage targets
- occupancy/construction basics
- prior coverage/loss indicators
- document upload

### Routing Rules
- Flood submissions -> flood queue
- Specialty/commercial -> line-specific queue
- Missing required fields -> exception queue

---

## 5) Brand + Visual Direction
- Professional MGA tone (clean, credible, not overdesigned)
- Strong contrast and readability
- Program cards and clear CTA hierarchy
- Avoid cluttered hero sliders
- Mobile-first interactions

---

## 6) Tracking + KPI Framework
Track at minimum:
- program page views
- submission starts
- submission completes
- partner inquiry submissions
- call/email click-throughs

Weekly KPIs:
- submission completion rate
- partner lead count
- quote turnaround time
- bind conversion by program

---

## 7) Backend Integration
- Unified intake backend with CD/QuoteRUSH workflows
- Lifecycle status standardization:
  New -> Intake Review -> Quote Ready -> Proposal Sent -> Won/Lost
- Exception handling for missing docs/fields
- Audit trail on edits and handoffs

---

## 8) Build Plan

### Phase 1 (2-3 days)
- Messaging architecture + wireframes
- Form field schema + routing rules

### Phase 2 (3-4 days)
- Build pages + responsive QA
- Integrations + events tracking

### Phase 3 (1-2 days)
- Launch + QA
- First optimization pass from live traffic
