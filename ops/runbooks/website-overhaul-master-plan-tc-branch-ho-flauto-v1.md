# Website Overhaul Master Plan (T&C + Branch + HOInsurance + FloridaAuto) v1

## Goal
Create a coordinated multi-site growth system where each domain has a clear role, distinct messaging, and one shared conversion backend.

## Site Role Map
- **Tomlinson & Co**: Core retail/local trust brand
- **Branch Agency Solutions**: MGA authority (flood + specialty)
- **HOInsurance.com**: Homeowners/flood acquisition funnel
- **FloridaAuto.com**: Auto-focused acquisition funnel

## Operating Principle
Different front-end brands, one backend pipeline.

## Shared Backend Standards
- Unified intake + tracking model
- Common lifecycle statuses
- Lead source/campaign attribution via UTM
- SLA-driven follow-up workflows

## Rollout Order
1) BranchAgencySolutions.com (authority anchor)
2) HOInsurance.com (fast conversion win)
3) FloridaAuto.com (parallelized template reuse)
4) T&C site enhancements to align brand system

## 30-Day Outcome Targets
- +30% quote-start volume
- +20% form completion rate
- <15 min median speed-to-first-contact during business hours
- Improved lead quality scoring by source/domain
