# 8x8 Runbook (Mode A: Inbound Notify Only)

## Goal
Receive inbound 8x8 webhook events and deliver readable alerts into OpenClaw chat.

## Current OpenClaw Mapping
- Hook path: `/hooks/8x8`
- Mapping name: `8x8`
- Action: `agent` + `wakeMode: now`
- Delivery: `deliver: true`, `channel: last`

## 8x8 Webhook Target
Set 8x8 callback URL to:
- `https://<YOUR_PUBLIC_URL>/hooks/8x8`

If you use tunnel/funnel, point to that external URL.

## Expected Payload Fields (current template)
The current message template expects these (optional) fields:
- `eventType`
- `from`
- `to`
- `direction`
- `status`
- `callId`
- `message`
- `id` (used for session key)

## Day-1 Test
1. Send a test webhook from 8x8 (or dev console) to `/hooks/8x8`
2. Confirm OpenClaw receives and posts event summary to chat
3. Place one real inbound call/SMS and confirm event appears

## Troubleshooting
- No event in chat:
  - Verify 8x8 callback URL is reachable from internet
  - Verify OpenClaw gateway is running
  - Verify `hooks.enabled=true` and mapping exists for path `8x8`
- Event appears but fields are blank:
  - 8x8 payload field names differ from template
  - Capture sample payload, then update mapping template field names

## Next Hardening (recommended)
- Add webhook signature verification (HMAC) once 8x8 signing format is confirmed
- Restrict source IPs if 8x8 publishes ranges
- Add idempotency handling for webhook retries
